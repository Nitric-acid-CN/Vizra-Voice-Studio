# 本机验证记录

2026-10-26，Windows，NVIDIA RTX 3060 Laptop 6GB，驱动 610.74。
三套独立环境，Python 3.12，CUDA PyTorch 2.6.0+cu124。一次一个模型，一个任务。

| 模型 / 语言 | 音频长度 | 纯推理耗时 | 峰值分配显存 | 精度 |
| --- | ---: | ---: | ---: | --- |
| Qwen VoiceDesign 1.7B / 中文 | 6.48 秒 | 13.66 秒 | 4182 MiB | FP16、SDPA |
| Qwen VoiceDesign 1.7B / 英文 | 5.36 秒 | 11.41 秒 | 4149 MiB | FP16、SDPA |
| Qwen Base 0.6B / 英文 | 5.04 秒 | 12.18 秒 | 2417 MiB | BF16、SDPA |
| CosyVoice3 0.5B / 英文 | 6.68 秒 | 5.81 秒 | 3361 MiB | 官方混合精度 |
| Chatterbox-Turbo / 英文 | 5.28 秒 | 14.79 秒 | 2793 MiB | 官方 FP32 路径 |
| Kokoro 82M / 英文 | 7.05 秒 | 1.52 秒 | 681 MiB | FP32 |

显存来自 `torch.cuda.max_memory_allocated()`，不含 CUDA context 等全部开销；
耗时包含生成及同步，不包含首次下载和完整冷启动。完整任务冷启动约 16～42 秒，
实际随磁盘、供电、温度和其他程序变化。没有在每种文本长度下承诺同一峰值。
Chatterbox/Kokoro 官方默认精度已经适合本机显存，未强行尝试未经验证的半精度或量化。

英文输入：

> This is a wireless head tracking module. It controls the camera and the view in a flight simulator.

Qwen VoiceDesign 的英文样本作为 Qwen Base、CosyVoice 和 Chatterbox 的参考音频。
Kokoro 使用 `am_michael` 预设。未使用用户收藏音色制作公开测试文件。
中文使用用户最初提供的无线头追测试文案。

## 音频验证

- SoundFile 能读取生成文件，采样率 24000，非空、数值有限且含有效声音。
- 五个英文样本经本机离线 SenseVoice 自动转写，忽略大小写/标点后，单词与输入一致。
- 英文样本首尾静音按 100ms 窗口/0.002 幅度阈值检查，首部 0～0.4 秒、尾部 0～0.6 秒。
- 自动转写、振幅检查不代表人工自然度评价，不能证明任意文本永远不截断。
- 中文自动转写出现“无限头锥”等同音词误识别，不能据此声称中文逐字转写完全一致。
- 公开 WAV 与脱敏指标见 [samples](samples/) 和 [validation.json](validation.json)。

Qwen Base、CosyVoice 中文已在此前本机部署阶段生成并验证。本次新增回归包含 VoiceDesign 中文；
其他中文样本不重复搬入公开包。语音质量、跨模型相似度、跨语言口音仍应由用户试听选择。

## 工作台功能验证

CPU 隔离测试通过：换行分段、英文单词边界、长稿不丢字、模型能力校验、
行内重做保留其他段落、恢复旧版本与对应文案、拼接覆盖固定文件、
真实 48kHz/PCM24 重采样及段落静音长度、删除整篇保留片段、预设项目恢复。

独立 Edge 浏览器使用测试信号完成：五模型能力切换、英文预设整篇生成、
行内重做旋转状态、版本增加、整篇过期提示、重新拼接及三个页面访问；无页面脚本错误。
截图中的项目为隔离验收数据，不是用户作品。

真实 Kokoro GPU 全流程另已通过：两段实际生成 → 只重做第一段（保留第二段文件哈希）→
自动选用新版本 → 重拼接。导出为 7.45 秒 48kHz/PCM24，段间静音 0.35 秒，
导出时长等于选中片段时长之和加静音（误差小于 1ms）。
